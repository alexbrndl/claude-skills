# 20 Design Philosophies

A library of named design philosophies for choosing a visual direction. Each entry: the designer/studio it comes from, its core philosophy, its signature traits, a prompt-DNA block (drop into an image-gen or brief, combine with your content), search keywords to find references, and when to reach for it.

**Rule: never name the philosophy as a style label** ("in the style of Pentagram"). Use the concrete traits and prompt DNA instead. **Never blend into a generic average** — pick 1, or deliberately combine 2 from *different* schools for contrast.

The 20 are grouped in 5 schools. When proposing directions, the strongest moves come from picking across schools, not two siblings.

| School | Visual temperament | Use as |
|---|---|---|
| Information Architecture (01-04) | Rational, data-driven, restrained | Safe / professional choice |
| Motion Poetics (05-08) | Kinetic, immersive, tech-forward | Bold / avant-garde choice |
| Minimalism (09-12) | Order, whitespace, refinement | Safe / high-end choice |
| Experimental Vanguard (13-16) | Generative, high-impact, rule-breaking | Bold / creative choice |
| Eastern Philosophy (17-20) | Warm, poetic, contemplative | Differentiated / distinctive choice |

## I. Information Architecture (01-04)
> Philosophy: "Data isn't decoration, it's a building material."

### 01. Pentagram — Michael Bierut
**Philosophy:** type is the language, the grid is the thinking.
**Traits:** extreme color restraint (black/white + one brand color); a modern reading of the Swiss grid; typography as the primary visual language; strategic negative space (60%+ whitespace).
**Prompt DNA:**
```
Pentagram / Michael Bierut style:
- Extreme typographic hierarchy, Helvetica/Univers family
- Swiss grid with precise mathematical spacing
- Black/white + one accent color (#HEX)
- Information architecture as visual structure
- 60%+ whitespace ratio
- Data visualization as primary decoration
```
**Reference work:** Hillary Clinton 2016 campaign identity.
**Search:** `pentagram hillary logo system`
**When:** editorial, institutional, type-led brands that want authority without ornament.

### 02. Stamen Design — data poetics
**Philosophy:** let data become a landscape you can touch.
**Traits:** cartographic thinking applied to information; organic, algorithm-generated patterns; warm data palette (terracotta, sage green, deep blue); layered interactive hierarchy.
**Prompt DNA:**
```
Stamen Design aesthetic:
- Cartographic approach to data visualization
- Organic, algorithm-generated patterns
- Warm palette (terracotta, sage green, deep blues)
- Layered information like topographic maps
- Hand-crafted feel despite digital precision
- Soft shadows and depth
```
**Reference work:** COVID-19 surge map.
**Search:** `stamen covid map visualization`
**When:** data-heavy products that should feel human and warm, not clinical.

### 03. Information Architects (iA) — content-first
**Philosophy:** design is not decoration, it is the architecture of content.
**Traits:** extreme content-hierarchy clarity; system fonts only (reading-optimized); the classic blue hyperlink tradition; performance as aesthetic.
**Prompt DNA:**
```
Information Architects philosophy:
- Content-first hierarchy, zero decorative elements
- System fonts only (SF Pro / Roboto / Inter)
- Classic blue hyperlinks (#0000EE)
- Reading-optimized line length (66 characters)
- Progressive disclosure of depth
- Text-heavy, fast-loading design
```
**Reference work:** iA Writer.
**Search:** `information architects ia writer`
**When:** reading apps, docs, long-form, anything where text is the product.

### 04. Fathom Information Design — scientific narrative
**Philosophy:** every pixel must carry information.
**Traits:** scientific-journal rigor meets design elegance; precise quantitative visualization; cool professional palette (grays, navy); footnote/citation systems treated as design.
**Prompt DNA:**
```
Fathom Information Design style:
- Scientific journal aesthetic meets modern design
- Precise data visualization (charts, timelines, scatter plots)
- Neutral scheme (grays, navy, one highlight color)
- Footnote/citation design integrated into layout
- Clean sans-serif (GT America / Graphik)
- Information density without clutter
```
**Reference work:** Bill & Melinda Gates Foundation annual report.
**Search:** `fathom information design gates foundation`
**When:** reports, research, dense dashboards that still need to read as designed.

## II. Motion Poetics (05-08)
> Philosophy: "Technology itself is a kind of flowing poetry."

### 05. Locomotive — scroll narrative
**Philosophy:** scrolling isn't browsing, it's a journey.
**Traits:** silky parallax scroll; cinematic scene-by-scene narrative; bold spatial whitespace; precise choreography of moving elements.
**Prompt DNA:**
```
Locomotive scroll narrative style:
- Film-like scene composition with parallax depth
- Generous vertical spacing between sections
- Bold typography emerging from darkness
- Smooth motion blur effects
- Dark mode (near-black backgrounds)
- Strategic glowing accents
- Hero sections 100vh tall
```
**Reference work:** Lusion.co.
**Search:** `locomotive scroll lusion`
**When:** premium marketing sites, product launches, story-driven landing pages.

### 06. Active Theory — WebGL poet
**Philosophy:** making technology visible makes it understandable.
**Traits:** 3D particle systems as the core element; real-time rendered data; mouse-driven world-building; neon-on-deep-space color.
**Prompt DNA:**
```
Active Theory WebGL aesthetic:
- Particle systems representing data flow
- 3D visualization in depth space
- Neon gradients (cyan/magenta/electric blue) on dark
- Mouse-reactive environment
- Depth of field and bokeh effects
- Floating UI with glassmorphism
```
**Reference work:** NASA Prospect.
**Search:** `active theory nasa webgl`
**When:** immersive experiences, awards-bait, tech showcases with real interactivity.

### 07. Field.io — algorithmic aesthetics
**Philosophy:** code is the designer.
**Traits:** generative-art systems; graphics that differ every visit; intelligent orchestration of abstract geometry; balance of technical and artistic.
**Prompt DNA:**
```
Field.io generative design style:
- Abstract geometric patterns, algorithmically generated
- Dynamic composition that feels computational
- Monochromatic base with vibrant accent
- Mathematical precision in spacing
- Voronoi diagrams or Delaunay triangulation
- Clean code aesthetic
```
**Reference work:** British Council digital installations.
**Search:** `field.io generative design`
**When:** brands that want a living, computational identity; data/AI companies.

### 08. Resn — narrative-driven interaction
**Philosophy:** every click advances the story.
**Traits:** gamified user journeys; strong emotional design; deep blend of illustration and code; non-linear exploration.
**Prompt DNA:**
```
Resn interactive storytelling approach:
- Illustrative style mixed with UI elements
- Gamified exploration (progress indicators)
- Warm color palette despite tech subject
- Character-driven design
- Scroll-triggered animations
- Editorial illustration meets product design
```
**Reference work:** Resn.co.nz portfolio.
**Search:** `resn interactive storytelling`
**When:** playful campaigns, kids/entertainment, brands that want personality and warmth.

## III. Minimalism (09-12)
> Philosophy: "Reduce until you can't remove anything more."

### 09. Experimental Jetset — conceptual minimalism
**Philosophy:** one idea = one form.
**Traits:** a single visual metaphor carries the whole design; Mondrian-style primaries (red/blue/yellow) + black/white; type as graphic; anti-commercial honesty.
**Prompt DNA:**
```
Experimental Jetset conceptual minimalism:
- Single visual metaphor for entire design
- Primary colors only (red/blue/yellow) + black/white
- Typography as main graphic element
- Grid-based with deliberate rule-breaking
- No photography, only type and geometry
- Anti-commercial, honest aesthetic
```
**Reference work:** Whitney Museum responsive identity.
**Search:** `experimental jetset whitney responsive w`
**When:** cultural institutions, type-forward brands, concept-driven identities.

### 10. Müller-Brockmann — Swiss grid purism
**Philosophy:** objectivity is beauty.
**Traits:** mathematically precise grid (8pt baseline); strict alignment (flush left or centered); one or two colors max; functionalism above all.
**Prompt DNA:**
```
Josef Müller-Brockmann Swiss modernism:
- Mathematical grid system (8pt baseline)
- Strict alignment (flush left or centered)
- Two-color maximum (black + one accent)
- Akzidenz-Grotesk or similar rationalist typeface
- No decorative elements
- Timeless, objective aesthetic
```
**Reference work:** *Grid Systems in Graphic Design*.
**Search:** `muller brockmann grid systems poster`
**When:** posters, systematic brands, anything that benefits from timeless rigor.

### 11. Build — contemporary luxury minimalism
**Philosophy:** refined simplicity is harder than complexity.
**Traits:** luxury-grade whitespace (70%+); subtle weight contrast (200-600); strategic single accent; a breathing rhythm.
**Prompt DNA:**
```
Build studio luxury minimalism:
- Generous whitespace (70%+ of area)
- Subtle typography weight shifts (200 to 600)
- Single accent color used sparingly
- High-end product photography aesthetic
- Soft shadows and subtle gradients
- Golden ratio proportions
```
**Reference work:** Build studio portfolio.
**Search:** `build studio london branding`
**When:** premium consumer, fashion, high-end product pages.

### 12. Sagmeister & Walsh — joyful minimalism
**Philosophy:** beauty is the emotional dimension of function.
**Traits:** unexpected color bursts; handmade-meets-digital; optimistic visual language; experimental but legible.
**Prompt DNA:**
```
Sagmeister & Walsh joyful philosophy:
- Unexpected color bursts on minimal base
- Handmade elements (physical objects in digital)
- Optimistic visual language
- Experimental typography that remains legible
- Human warmth through imperfection
- Mix of analog and digital aesthetics
```
**Reference work:** The Happy Show.
**Search:** `sagmeister walsh happy show`
**When:** lifestyle, wellness, brands that want energy and human warmth.

## IV. Experimental Vanguard (13-16)
> Philosophy: "Breaking the rules is making the rules."

### 13. Zach Lieberman — code as poetry
**Philosophy:** programming is painting.
**Traits:** hand-drawn-feeling algorithmic graphics; real-time generative art; pure black-and-white; the tool/process kept visible.
**Prompt DNA:**
```
Zach Lieberman code-as-art style:
- Hand-drawn aesthetic generated by code
- Black and white only, no color
- Real-time generative patterns
- Sketch-like line quality
- Visible process/grid/construction lines
- Poetic interpretation of algorithms
```
**Reference work:** openFrameworks creative coding.
**Search:** `zach lieberman openframeworks generative`
**When:** creative-coding portfolios, art-tech, experimental microsites.

### 14. Raven Kwok — parametric aesthetics
**Philosophy:** the beauty of the system beats the beauty of the individual.
**Traits:** fractal and recursive structures; high-contrast black and white; architectural data structures; Chinese-garden principles rendered as algorithm.
**Prompt DNA:**
```
Raven Kwok parametric aesthetic:
- Fractal patterns and recursive structures
- High-contrast black and white
- Architectural visualization of data
- Chinese garden principles in algorithm form
- Intricate detail that rewards zooming
- Processing/Creative coding aesthetic
```
**Reference work:** Raven Kwok generative-art exhibitions.
**Search:** `raven kwok processing generative art`
**When:** generative identities, intricate visual systems, art installations.

### 15. Ash Thorp — cyber poetics
**Philosophy:** the future isn't cold, it's a lonely poem.
**Traits:** film-grade lighting; a warm cyberpunk (orange/teal, not cold blue); narrative concept-art feel; refined industrial aesthetics.
**Prompt DNA:**
```
Ash Thorp cinematic concept art:
- Film-grade lighting and atmospheric effects
- Warm cyberpunk (orange/teal, NOT cold blue)
- Industrial design meets luxury
- Narrative concept art feel
- Volumetric lighting and god rays
- Blade Runner warmth over Tron coldness
```
**Reference work:** Ghost in the Shell concept art.
**Search:** `ash thorp ghost shell concept art`
**When:** film/game promo, sci-fi product worlds, cinematic launches.

### 16. Territory Studio — FUI (fantasy user interface)
**Philosophy:** today's imagination of tomorrow's UI.
**Traits:** sci-fi screen design; holographic projection feel; orange/amber monochrome or cyan accents; multiple overlapping data layers; believable future tech.
**Prompt DNA:**
```
Territory Studio FUI (Fantasy User Interface):
- Fantasy User Interface design
- Holographic projection aesthetics
- Orange/amber monochrome or cyan accents
- Multiple overlapping data layers
- Believable future technology
- Technical readouts and data streams
```
**Reference work:** Blade Runner 2049 screen graphics.
**Search:** `territory studio blade runner interface`
**When:** hardware, futuristic dashboards, sci-fi data displays.

## V. Eastern Philosophy (17-20)
> Philosophy: "Negative space is the content."

### 17. Takram — Japanese speculative design
**Philosophy:** technology is a medium for thinking.
**Traits:** elegant concept prototypes; soft tech (rounded corners, gentle shadows); charts as art; modest sophistication.
**Prompt DNA:**
```
Takram Japanese speculative design:
- Elegant concept prototypes and diagrams
- Soft tech aesthetic (rounded corners, gentle shadows)
- Charts and diagrams as art pieces
- Modest sophistication
- Neutral natural colors (beige, soft gray, muted green)
- Design as philosophical inquiry
```
**Reference work:** NHK Fabricated City.
**Search:** `takram nhk data visualization`
**When:** thoughtful tech brands, R&D, speculative or future-facing products.

### 18. Kenya Hara — the design of emptiness
**Philosophy:** design is not filling, it is emptying.
**Traits:** extreme whitespace (80%+); paper texture and tactility in digital form; layered whites (warm white, cool white, off-white); design by subtraction.
**Prompt DNA:**
```
Kenya Hara "emptiness" design:
- Extreme whitespace (80%+)
- Paper texture and tactility in digital form
- Layers of white (warm white, cool white, off-white)
- Minimal color (if any, very desaturated)
- Design by subtraction not addition
- Zen simplicity
```
**Reference work:** Muji art direction; *Designing Design*.
**Search:** `kenya hara designing design muji`
**When:** quiet premium brands, wellness, products where calm is the message.

### 19. Irma Boom — book architecture
**Philosophy:** the physical poetics of information.
**Traits:** non-linear information structure; play with edges, margins, boundaries; unexpected color combos (pink+red, orange+brown); handcraft translated to digital.
**Prompt DNA:**
```
Irma Boom book architecture style:
- Non-linear information structure
- Play with edges, margins, boundaries
- Unexpected color combos (pink+red, orange+brown)
- Handcraft translated to digital
- Dense information inviting exploration
- Editorial design, unconventional grid
```
**Reference work:** SHV Think Book (2136 pages).
**Search:** `irma boom shv think book`
**When:** editorial, art-book microsites, brands that reward exploration.

### 20. Neo Shen — Eastern light & shadow poetics
**Philosophy:** technology needs human warmth.
**Traits:** digital ink-wash diffusion; soft glow and light bloom; poetic negative space; emotional palette (deep blue, warm gray, soft gold); calligraphic type influence.
**Prompt DNA:**
```
Neo Shen poetic Chinese aesthetic:
- Digital interpretation of ink wash painting
- Soft glow and light diffusion effects
- Poetic negative space
- Emotional palette (deep blues, warm grays, soft gold)
```

**Reference work:** Neo Shen digital art series.

**When:** atmospheric brands, culture-forward products, emotional storytelling.

## Using the prompt DNA

Combine: `[philosophy prompt DNA] + [content description] + [output spec]`.

**Describe mood, not layout.** Short prompts beat long ones for image generation. Three sentences of mood and content beat thirty lines of layout detail.

| Kills variety | Sparks creativity |
|---|---|
| Color ratios (60%/25%/15%) | A mood ("warm like Sunday morning") |
| Fixed positions ("title centered, image right") | A concrete reference ("Pentagram editorial feel") |
| Listing every visual element | Describe what the viewer should feel |

Default aesthetic bans (override per brand): cyber-neon / deep-blue `#0D1117` backgrounds; personal signatures/watermarks on covers.
